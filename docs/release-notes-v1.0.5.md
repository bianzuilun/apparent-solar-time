# 真太阳时 v1.0.5（Android）

修复桌面小组件在零点缺少小时位、跨日计时累计及后台时辰更新不及时的问题，并补充后台校准的恢复机制。

## 更新

- 小组件时间统一补齐为 `HH:MM:SS`，如 `00:50:21`、`01:00:00`；补零不再依赖精确闹钟权限或整点刷新。
- 每个真太阳整点使用唤醒闹钟校准时间和时辰，计算下一整点时计入均时差变化。
- 加入系统约 30 分钟周期更新作为兜底；点击组件、调整大小或授予精确闹钟权限后重新校准。
- 精确闹钟不可用或权限被撤销时自动使用不精确闹钟。
- 真太阳时与均时差的核心计算算法保持不变；更新 README 中的权限、刷新机制和厂商适配说明。

## 安装与权限

下载 `apparent-solar-time-v1.0.5.apk`，支持 Android 8.0 及以上。沿用正式签名，可覆盖安装此前使用同一正式签名的版本。

零点补零无需授权。仍建议授予「闹钟和提醒」权限，以减少整点、午夜和换时辰的校准延迟。未授权时及厂商极限省电、强制停止状态下，后台校准可能被系统推迟；点击组件可立即校准。
