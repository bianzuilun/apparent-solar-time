# 真太阳时 v1.0.0（Android）

首个正式版本。根据当前定位计算真太阳时（视太阳时），桌面小组件按秒实时刷新。

## 功能

- 🛰️ 自动定位（GPS / 网络 / 融合定位，无 Google Play 依赖），支持手动输入经纬度
- ⏱️ 主界面实时显示真太阳时、均时差、经度修正、时区与定位状态
- 📱 桌面小组件按秒走字，支持缩放；整点自动校准，误差 < 1 秒
- 🔋 零后台：无前台服务、无轮询，息屏无活动
- 🧮 Meeus 天文算法（含章动、光行差），精度优于 ±1 秒，8 项单元测试与 NOAA 参考值比对

## 真机验证（vivo V2502A，厦门 24.50°N 118.18°E）

| 项目 | 实测 |

## 安装

1. 下载下方 `真太阳时-v1.0.0.apk` 安装（需允许安装未知来源应用）
2. 打开 App，允许定位权限
3. 长按桌面空白处 → 组件/原子组件 → 找到「真太阳时」添加到桌面
4. 建议授予「闹钟和提醒」（精确闹钟）权限，保证整点/午夜精准校准（App 内有一键跳转）

> 注意：APK 使用项目正式签名，签名密钥不随源码发布。此前安装过调试版（如通过 adb 直接构建安装）的设备需先卸载再安装本版本。

## 已知限制

- 无精确闹钟权限时，真太阳时 0~1 点显示为 `M:SS`（缺小时前导零），数值仍正确
- 未做 UT1/DFUT1 修正（与地球真实自转差异 < 1 秒，对显示无影响）
- 仅支持 Android 8.0（API 26）及以上
